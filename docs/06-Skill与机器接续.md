# Skill与机器接续

## 接入方式

本包Skills随河图插件注册，外部Codex经同一稳定CLI/MCP即时发现`skills.read`，读取`hetu-art-direction`入口及按需参考。不向Codex安装同名插件，不增加永久客户端工具名，安装生命周期与作品管理连接分开。

## 默认旅程

读取当前作品实体与固定图片→建立参考板与图像职责→整理色板与造型要求→实际渲染并按区域提意见→比较设计方案→外部工具制作候选→按固定素材接续。

方法入口为[SKILL](../skills/hetu-art-direction/SKILL.md)，[操作地图](../skills/hetu-art-direction/references/operations.md)随清单生成，[流程](../skills/hetu-art-direction/references/workflows.md)描述专业决策。

## 有界发现与内容

先发现当前包摘要与专业Schema，再精确读取必要宿主动作。不全量加载所有插件方法，不用压缩摘要冒充已读原文。大成果使用summary与固定分块完整核验；只读投影不改变写入原输入。

## 恢复与用户决定

未知写入先查原键；同输入明确未落盘才恢复，不换键重复写入。CAS冲突保留输入。Agent执行准备与确定性事务，作者保留采纳、定稿、费用和外发决定。宿主拥有图片原字节、来源、人物身份及正式选用。本包selected仅为专业方案偏好，不选用宿主素材；不能由色板对比度证明审美、人物一致性或素材权利。使用实际PNG/JPEG，完整解码由界面验收证明；不自动联网抓图或付费生成。
